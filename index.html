📖 КНИГА РЕЦЕПТОВ (ШПААРГАЛКА)

1. ДИСКРИМИНАНТ (D)

Для уравнения: ax² + bx + c = 0

Формула: D = b² - 4ac

  • D > 0 → 2 разных корня ($x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}$)
  • D = 0 → 1 корень ($x = \frac{-b}{2a}$)
  • D < 0 → 0 действительных корней

2. ТЕОРЕМА ВИЕТА

Для приведенного уравнения: x² + px + q = 0

x₁ + x₂ = -p (Сумма равна -b)

x₁ · x₂ = q (Произведение равно c)

3. ОБРАТНАЯ ТЕОРЕМА ВИЕТА

Зная корни x₁ и x₂, можно составить уравнение:

x² - (x₁ + x₂)x + (x₁ · x₂) = 0

Пример: корни 2 и 3 → x² - 5x + 6 = 0
